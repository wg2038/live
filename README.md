《live · 14亿分之1》（China Birth Simulator）是一款深度参考并致敬《80亿分之1》(1in8b.life) 的现代极简典雅风历史人生模拟网页游戏。网页采用 1:1 现代简约杂志风排版、支持深色/浅色模式平滑切换，以客观冷峻的真实人口历史统计为基石。玩家无法选择出身，在近百年风云变迁与自然天灾浩劫中，一年一年走完属于中国普通人的一生。

## 🏛 核心设计与历史纵深

- **严格的真实历史区间（1937–2026）**：全部为已发生的真实历史，不做任何虚妄的未来预测。
- **全中国地级市与典型县级市深度覆盖**：
  - 收录全国 **31 个省/直辖市/自治区**、**149 个典型地级市及代表性县级市**；
  - 动态还原地名沿革（如 1978 年前出生于深圳显示为“宝安县”，1985 年前东莞显示为“东莞县虎门太平”，1965 年前攀枝花显示为“渡口公社”）；
  - 覆盖**重工业资源型、大三线军工型、传统农业劳务大市、沿海商贸外贸型、民营轻工集群型、综合科教中心、边陲农牧林业型、贫瘠特困型**等 8 大产业母型在四大历史时期的工业演进与典型父母工种。
- **1937–2026 特大自然灾害全息数据库**：
  - 涵盖 1938 花园口黄泛、1942 中原旱蝗、1954 长江大水、1966 邢台地震、1975 驻马店“75·8”特大溃坝、1976 唐山大地震、1987 大兴安岭火灾、1998 全流域洪水、2008 南方冰雪与汶川特大地震、2010 舟曲泥石流、2021 郑州“7·20”特大暴雨、2023 海河特大暴雨等；
  - 当年角色身处灾区时，自动触发地缘天灾生死骰判定（罹难、伤残、失亲、破产或奇迹生还）。
- **五代人血肉人名谱系引擎**：
  - 1937–1949：宗族字辈、乱世贱名与期盼（铁蛋、狗剩、长庚、振邦、招娣、佩兰）；
  - 1950–1965：建国初潮与劳动奉献（建国、援朝、保国、跃进、素珍、秀荣）；
  - 1966–1976：红色浪潮与忠字印记（卫东、向阳、红兵、立新、秀英、红梅）；
  - 1977–1999：单字风潮与通俗文化（伟、磊、超、强、静、艳、丽、娜）；
  - 2000–2026：千禧古风与言情生僻（浩然、子轩、宇航、欣怡、梓涵、语桐）；
  - 并设岭南（阿强、焯林、泳仪）、东北（铁柱、翠花）、少数民族（扎西、买买提、巴特尔等）地域支线。
- **最新时代历史切片（2020–2026）**：
  - 2020 突发疫情与除夕全国静默；
  - 2022 常态化防控、静默管理与小微生计阵痛；
  - 2022–2023 疫情防控平稳转段与首轮高烧波峰；
  - 2023–2024 生成式 AI 狂飙冲击初级白领就业与“考公考编”狂潮；
  - 2024–2026 渐进式延迟法定退休年龄与深度老龄化时代。
- **千人千面：0–80岁动态职业进阶树与社会圈层深度分化**：
  - **六大职业发展轨道**：产业工人、农业耕作、公职教师/医护、小微商贸、科技白领、灵活交运，从学徒、青工、骨干、车间主任/教研组长一直演进至银发退养；
  - **摒弃虚妄的“塞翁失马”说教**：彻底移除悖论式宿命说教，42 项重大时代抉择扎根于真实的工薪积累、产业变迁、家庭责任与健康取舍；
  - **重大时代关卡多圈层分化（以 2022 年为例）**：告别“千人一面送外卖”，动态适配为高龄退休老人（慢病送药通道与楼道互助）、高校青年（闭环答辩与考公备考大军）、公职教师（线上授课与下沉网格包保）、工矿技工（驻厂气泡闭环保产）、科技白领（居家远程会议与降本增效）、个体商户（社区保供团长与租金博弈）；
  - **四重纪实叙事交织系统**：每一年的纪实流动态融合【时代宏观脉搏】+【工种感官与具体工具】+【家庭温饱承载】+【精力灌注印记】，严格呈现 80–150 字有血有肉的生活细节。
- **生平终局与追思馆**：
  - 一生里程碑时间轴、亲历天灾烙印展示；
  - 与同时代出生人口的大致排位对比（寿命、受教育程度、家境财富）；
  - 追思馆留言板（自动保存在本地 `localStorage`）；
  - 一键生成仿宣纸古典文献质感的【生平档案卡】（Canvas 绘制，支持一键导出 PNG）。

## 🎮 玩法循环

1. **每年纪实叙事**：生成一段 80–150 字的克制叙事（时代宏观背景 + 个人微观生活处境）；
2. **精力自主分配**：将固定 100 点精力动态调节于【学业】、【劳作】、【家庭】、【休养】；
3. **关键十字路口抉择**：在读书求学、参军支前、上山下乡、恢复高考、改革下海、婚育买房、就医治病等关卡权衡利弊；
4. **终局评定**：走完一生后，查看生平档案与同龄人统计对比，并在追思馆为角色留下一纸悼词。

## 🚀 一键开启 GitHub Pages (方便朋友在线试玩)

本项目采用**纯前端零依赖**设计，所有数据和逻辑均运行在浏览器端，完美适配手机与电脑，天生支持 GitHub Pages 免费部署！

### 第一步：上传到你的 GitHub 仓库

如果你已经在本地创建了该仓库，只需在终端执行：

```bash
# 1. 确保位于项目目录
cd live

# 2. 关联你的 GitHub 远程仓库
git remote add origin https://github.com/wg2038/live.git

# 3. 推送到 main 分支
git branch -M main
git push -u origin main
```

### 第二步：在 GitHub 网页开启 GitHub Pages（仅需点 3 下）

1. 打开你在 GitHub 上的 `live` 仓库页面；
2. 点击仓库顶部的 **Settings**（设置）选项卡；
3. 在左侧菜单点击 **Pages**；
4. 在 **Build and deployment** 下的 **Branch** 处：
   - 将分支选择为 **`main`**；
   - 目录保持为 **`/ (root)`**；
   - 点击 **Save**（保存）；
5. 等待约 1 分钟刷新页面，GitHub 会在上方生成专属的在线访问网址：
   `https://wg2038.github.io/live/`

**直接把这个链接发给微信群或朋友，手机浏览器点开即可立即试玩！**

## 💻 本地运行与调试

如果想在本地电脑上体验或继续修改代码：

```bash
# 进入项目目录
cd live

# 启动本地快速 HTTP 服务
python3 server.py

# 在浏览器中打开提示的网址 (默认 http://localhost:8080)
```

> **注**：代码内置了 `data/embedded.js` 自动容错机制，即便本地不启动服务器直接双击 `index.html` 打开，也不会因跨域报错而白屏，可直接运行。
